# 🍅 TomatoVision AI - Intelligent Tomato Leaf Disease Detection

### 🎯 Detect 10 Types of Tomato Diseases in Seconds | Built with Deep Learning

An AI-powered solution to help farmers detect tomato plant diseases early and prevent crop loss. Just upload a leaf image and get instant prediction!

---

### 📸 Features
- ✅ Detects 10 classes: 9 Diseases + Healthy
- ✅ Instant prediction with confidence score
- ✅ Clean & Simple Streamlit UI
- ✅ Model: tomato_model_v4.keras (Custom CNN)

**Diseases Detected:** Bacterial Spot, Early Blight, Late Blight, Leaf Mold, Septoria Leaf Spot, Spider Mites, Target Spot, Yellow Leaf Curl Virus, Mosaic Virus

---

### 🛠️ Tech Stack
- Python, TensorFlow, Keras
- OpenCV, Pillow, NumPy
- Streamlit for UI
- Convolutional Neural Network (CNN)
